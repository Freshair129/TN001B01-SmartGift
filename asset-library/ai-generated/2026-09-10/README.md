# SmartGift AI Image Library

วันที่จัดเก็บ: 2026-09-10

- ภาพไม่ซ้ำ 48 ภาพ / ผูกรหัสจากหลักฐานเดิมได้ 45 ภาพ
- เปิด `index.html` เพื่อดูภาพและค้นหาชื่อ รหัส หรือกลุ่มสินค้า
- `image-index.csv` เป็นดัชนีที่เปิดด้วย Excel ได้
- `manifest.json` เก็บ SHA-256, แหล่งไฟล์เดิม, คำอธิบายสินค้า และ prompt เฉพาะที่กู้คืนได้จริง
- `images/` เก็บไฟล์ภาพต้นฉบับแบบไม่แก้ไขพิกเซล ตรวจเทียบ SHA-256 แล้ว
- ภาพทั้งหมดเป็น AI ยังไม่ยืนยันว่าตรงกับรุ่นจริง และไม่ใช่ภาพแคตตาล็อกที่อนุมัติแล้ว
- source-guided-ai-isolation คือภาพทดลองแยกเมาส์จาก Offer FXD8812 ด้วย AI ยังต้องตรวจความเที่ยงตรง
- ภาพที่ยังไม่ทราบรหัสเก็บในชื่อ unmapped ไม่เดาชื่อหรือผูกรหัสขึ้นใหม่
- ไฟล์ต้นทางเดิมยังคงอยู่ การจัดเก็บครั้งนี้คัดลอกเข้าโฟลเดอร์คลังภาพ ไม่ลบหรือย้ายต้นทาง
